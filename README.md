# order-find-ks

Скил (навык) для ИИ-ассистента Kimi. Ищет и отбирает заказы на фриланс-биржах под профиль исполнителя: фильтрует по критериям, проверяет красные флаги, даёт вердикт по каждому заказу и готовит черновик первого отклика.

## Когда срабатывает

1. Просят найти или подобрать заказы на фриланс-бирже.
2. Просят оценить конкретный заказ перед откликом.
3. Просят написать отклик на заказ.

## Как работает

1. Уточняет критерии: какие биржи смотреть (Kwork, FL.ru, Habr Freelance, YouDo, Авито Услуги, Профи), типы работ, минимальный бюджет, регион и формат.
2. Собирает только свежие заказы - не старше 7 дней от даты публикации.
3. Фильтрует по критериям и проверяет каждый заказ на красные флаги: «сделай тестовое бесплатно», «нужно вчера», бюджет ниже рынка, расплывчатое ТЗ и другие.
4. Выдаёт по каждому заказу вердикт: откликаться / пропустить / осторожно, с причинами.
5. Формирует шорт-лист из 3-5 лучших заказов с черновиком первого отклика и сохраняет полный список файлом.

## Железные правила

- Скил не отправляет отклики и не пишет заказчикам сам. Всё, что уходит заказчику, пользователь отправляет сам после проверки.
- Скил не выдумывает заказы, ссылки, бюджеты и даты. Если данные заказа проверить не удалось, он так и скажет.

## Пример

Запрос: «Найди заказы на лендинги от 15 тысяч». Скил уточнит биржи и регион, соберёт свежие заказы, отсеет сомнительные, даст шорт-лист с вердиктами и черновики откликов, а полный список сохранит файлом «Подборка - Заказы - ГГГГ-ММ-ДД.md».

## Установка в Kimi

1. Откройте создание скила командой /skill-creator.
2. Вставьте текст из файла SKILL.md.
3. Сохраните скил и проверьте тестовым запросом на подбор заказов.
